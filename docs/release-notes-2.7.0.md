# ShapeShifter 2.7.0

## New: updates
- ShapeShifter checks GitHub once a day and shows a notification and a tray entry (**Update to x.y.z…**) when a newer version is out.
- **Update now** downloads the installer, checks it against its published SHA-256, and installs over the current version. Your settings and hotkeys are kept and ShapeShifter restarts.
- **Check for updates…** is in the tray menu and in Settings › About, where the daily check can be switched off. **Skip this version** silences one release.

## Good to know
- Versions before 2.7.0 have no updater, so install this one by hand; later versions can update themselves.
- The installer is not code-signed, so SmartScreen may warn: choose **More info > Run anyway**. It upgrades earlier versions in place.

**Download:** `ShapeShifter-Setup-2.7.0.exe` (Windows 10/11, 64-bit). Verify it against `SHA256SUMS.txt`.
