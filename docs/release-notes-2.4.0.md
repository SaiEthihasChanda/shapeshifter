# ShapeShifter 2.4.0

**Fill in forms that are only pictures.** Choose **FILL FORM** on the wheel for a photo or scan of a form.
ShapeShifter finds the blanks, check boxes and signature lines; you type the answers, tick boxes and add a signature
(draw it or import a picture); it saves a filled copy next to the original, which is never changed.

**Also new**
- **Word + picture** for images: puts the picture on a Word page so you can add text, then convert back to an image or PDF.
- One pink **Inferred** group on the wheel for everything that comes from reading a file's contents: Fill form, OCR to
  Word/text/Markdown/HTML, Word + picture and OCR PDF.
- `shapeshifter fill` on the command line.

**Download:** `ShapeShifter-Setup-2.4.0.exe` (Windows 10/11, 64-bit). Verify it against `SHA256SUMS.txt`.
The installer is not code-signed, so SmartScreen may warn: choose **More info > Run anyway**. It installs per user and
upgrades earlier versions in place.
