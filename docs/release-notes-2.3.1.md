# ShapeShifter 2.3.1

**New:** images now have a **Word + picture** option. It puts the photo on a Word page, so you can add text
in Word and convert the document back to an image or PDF with the text included. (The existing *Word* option
for images is OCR: it keeps only recognised text, not the picture.)

**Download:** `ShapeShifter-Setup-2.3.1.exe` (Windows 10/11, 64-bit, about 148 MB). Verify it against `SHA256SUMS.txt`.

The installer is not code-signed, so Windows SmartScreen may say "Windows protected your PC".
Choose **More info > Run anyway**. It installs per user and upgrades 2.3.0 in place.
