# ShapeShifter 2.3.0

Convert any file to another format in place: select a file, press **Ctrl+Alt+C**, pick a format on the wheel.

**Download:** `ShapeShifter-Setup-2.3.0.exe` (Windows 10/11, 64-bit, about 148 MB). Verify it against `SHA256SUMS.txt`.

## Highlights
- Multi-ring wheel, type-to-search, and conversions that route through intermediate formats.
- OCR, and PDF/document conversions that keep images, links and tables.
- Interactive graph of every format and conversion in Settings.

## Installing
The installer is not code-signed, so Windows SmartScreen may say "Windows protected your PC".
Choose **More info > Run anyway**. It installs for your account only and needs no administrator rights.
