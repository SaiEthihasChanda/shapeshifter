# ShapeShifter 2.9.0 — now on Mac

## New: ShapeShifter for Mac (Apple Silicon)
The same app as on Windows, on M1 and newer Macs with macOS 12 or later.
- **Right-click › Quick Actions › Convert with ShapeShifter** in Finder opens the wheel for the selected files.
- **Hotkeys** (⌃⌥C opens the wheel) and **mouse triggers** over Finder windows and the desktop.
- Everything else as on Windows: the wheel and its themes, Fill form, Properties, combining files, every converter (ffmpeg included), and text recognition with the one built into macOS. Originals go to the Trash.
- Lives in the menu bar and starts when you log in. Updates install themselves.

**Installing on a Mac:** open `ShapeShifter-macOS.dmg` and drag ShapeShifter onto Applications. The app isn't notarised by Apple, so the first time macOS says it can't check it: open **System Settings › Privacy & Security**, scroll down and click **Open Anyway** next to ShapeShifter (once). For the hotkeys, macOS asks for **Accessibility** and **Automation › Finder**; Settings › General shows whether they're on.

## Windows
No changes in how it works; this release shares its code with the Mac version.

**Downloads:** `ShapeShifter-Setup-2.9.0.exe` (Windows 10/11, 64-bit) and `ShapeShifter-macOS.dmg` (Mac, Apple Silicon). Verify the Windows installer against `SHA256SUMS.txt`; GitHub shows the SHA-256 of every file.
