# ShapeShifter 2.10.0 — Settings, redesigned

## Settings
- **A cleaner look**: every page now uses the same card-based design instead of the system's native group boxes, so Settings reads as one consistent app in both light and dark mode.
- **Reorganised for everyday use**: the side list is grouped — General, Wheel, Hotkeys, Formats and Engines are always shown; a new **Advanced** page and the **Graph** page sit below a divider for when you need them; About is pinned to the bottom.
- **Advanced** collects what most people never touch: JPEG/WEBP/AVIF quality and PDF resolution, "prefer native converters," the OCR language picker, the wheel's ring size and hover-to-convert, learned reverse conversions, custom formats, and exporting the conversion graph (DOT/JSON).
- General, Wheel and Formats & mappings are shorter now, each with one clear job. The old text-only route finder on Formats is gone — the Graph page's own route finder, with its interactive 3D view, already does this better.

## Good to know
- Windows and Mac (Apple Silicon) users already on 2.9.0 are offered this update from the tray / menu bar.
- The Mac app is still not notarised by Apple, so the first launch needs "Open Anyway" in Privacy & Security.

**Downloads:** `ShapeShifter-Setup-2.10.0.exe` (Windows 10/11, 64-bit) and `ShapeShifter-macOS.dmg` (Mac, Apple Silicon). Verify the Windows installer against `SHA256SUMS.txt`.
