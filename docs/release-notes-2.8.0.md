# ShapeShifter 2.8.0

## Fill form: finds far more of the form
- **Dotted lines** ("........"), second lines with no label, and several blanks on one line ("FROM THE …… day of …… 20……", "__ / __ / ____").
- **Blanks inside sentences** ("I, ______, residing at ______") are named from the sentence ("my mobile number is").
- **Tables**: every empty cell becomes a field, named by its row and column ("Name — Wrong Entry"). Boxes are named by the heading above them.
- **Signatures** printed under a line or an empty space are placed above their caption.
- **Crooked or grey scans and photos** are straightened before they are read, so the answers still land on the lines.
- Words the text reader skipped (a lone "No" beside a check box) get a second, closer look; junk fields from long sentences are gone.

## Fill form: you're in control
- **Move and resize** any field: drag its frame, or drag its edges and corners. Arrow keys nudge it (Shift for bigger steps), Delete removes it.
- **Any font installed in Windows** for the writing, plus a size you type in percent.
- **Per answer**: select a field to give just that answer its own font and size.

## Good to know
- If you have 2.7.0, ShapeShifter offers this update itself (tray › Check for updates…). Older versions: install by hand.
- The installer is not code-signed, so SmartScreen may warn: choose **More info > Run anyway**. It upgrades earlier versions in place.

**Download:** `ShapeShifter-Setup-2.8.0.exe` (Windows 10/11, 64-bit). Verify it against `SHA256SUMS.txt`.
