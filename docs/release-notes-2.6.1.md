# ShapeShifter 2.6.1

A tidier wheel.

- **Several files selected:** the "ONE GIF / ONE PDF / ONE TIFF …" entries are gone. Pick GIF (or PDF, TIFF, WebP, PPTX) and it asks **separate** or **all in one**. Formats with no per-file conversion of their own, such as a slideshow video, keep a **ONE …** entry.
- **NO LOCATION** now lives inside **PROPERTIES**, and only appears when the picture has location or camera data. A picture with nothing to remove opens the properties window directly.

**Download:** `ShapeShifter-Setup-2.6.1.exe` (Windows 10/11, 64-bit). Verify it against `SHA256SUMS.txt`.
The installer is not code-signed, so SmartScreen may warn: choose **More info > Run anyway**. It upgrades earlier versions in place.
